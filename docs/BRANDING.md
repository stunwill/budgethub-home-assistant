# Fynvo Branding

The Fynvo logo supplied with the v0.5.0 development request is the canonical product logo.

It contains:

- stylised blue F mark;
- Fynvo wordmark;
- blue/navy identity;
- white/light background.

## Repository assets

Application assets added in v0.5.0:

```text
fynvo/frontend/src/assets/fynvo-logo.svg
fynvo/frontend/src/assets/fynvo-mark.svg
fynvo/frontend/public/favicon.svg
```

`fynvo-logo.svg` is used for the login screen and product identity. `fynvo-mark.svg` is used in the sidebar and compact app chrome. `favicon.svg` is used by the browser and Home Assistant ingress web view where supported.

## Usage rules

- Do not stretch or distort the logo.
- Use the mark for compact spaces.
- Use the full logo where there is enough horizontal/vertical room.
- Keep the blue/navy identity consistent across Home Assistant and the web app.
- Future PWA or Home Assistant icon variants should be derived from the canonical logo.
